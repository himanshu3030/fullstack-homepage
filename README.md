# Fullstack Homepage Project


A modern full-stack homepage application with backend and frontend components.

## Features

- **Frontend**: Interactive user interface built with [React/Next(14)]
- **Admin Panel**: Management dashboard for content control
- **Backend**: Robust API service using [Node.js/Express]
- **Database**: [MongoDB] integration

## Technologies

### Frontend
- [React/Next(14)] - Frontend framework
- [TailwindCSS/ShadCN] - Styling framework
- [Axios/Fetch] - API communication

### Backend
- [Node.js] - Runtime environment
- [Express] - Web framework
- [Mongoose] - Database

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm
- [MongoDB] (if using local database)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/fullstack-homepage.git
   cd fullstack-homepage

  ### Install dependencies for both frontend and backend:
      cd backend && npm install
      cd ../frontend && npm install
      cd ../frontend-admin && npm install

  ### Running the Application
  Step : 1 Start the backend server:
            cd backend
            npm run dev

  Step : 2 Start the frontend development server:
             cd frontend
             npm run dev

  Step : 3 Start the admin panel:
             cd frontend-admin
             npm run dev
